# OpenStock Design Audit

## Reference audited

- Daybreak landing: https://www.daybreakcircles.lol/
- Daybreak app: https://www.daybreakcircles.lol/app
- App routes inspected: groups, holdings, profile, launch, world, and references.

## Design read

OpenStock is a trust-first tokenized-stock product for design-conscious crypto users. The visual language should be playful and memorable, but its hierarchy must behave like a serious execution product.

## Borrow

- Pale porcelain canvas with an electric-blue signature accent.
- Strong display typography and generous whitespace.
- Floating rounded navigation shell.
- Editorial section sequencing instead of a generic feature grid.
- Illustrated characters with physical presence.
- Live pulse rail, staggered reveals, floating assets, and soft modal transitions.
- Mobile sticky navigation and a coherent dark-mode transformation.

## Improve

- Replace social/memecoin discovery as the main promise with source verification and execution safety.
- Put the verdict, data freshness, and route information ahead of decorative motion.
- Make every animated status available as text.
- Use characters as guides for reference price, liquidity, multipliers, and receipts.
- Make connection and signing happen only after users understand the safety model.

## Avoid

- Copying Daybreak’s characters, silhouettes, phrases, layout, or exact compositions.
- Generic AI-purple gradients, generic glass everywhere, or default dashboard cards.
- Motion that implies a bullish direction or guaranteed return.
- A basket, copy-trading, lending, or generic trading-terminal product.

## Motion and scroll captured

The audit captured hero reveals, staggered cards, character drift, ticker movement and hover pause, modal fade/scale, theme transitions, mobile sticky navigation, and reduced-motion behavior. The OpenStock-specific choreography is defined in `OPENSTOCK_CHARACTER_MOTION_SPEC.md`.

## Product dials

- Landing: design variance 8, motion intensity 7, visual density 3.
- App: design variance 6, motion intensity 5, visual density 6.
- Safety surfaces override aesthetic intensity.
